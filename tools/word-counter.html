كيف أحسب الكلمات والحروف والأسطر في نص عربي، وما الفرق بين الحروف مع المسافات وبدونها؟

ألصق النص أو اكتبه لمشاهدة عدد الكلمات والحروف والأسطر، مع عدد الحروف دون مسافات أثناء التحرير.

عداد الكلمات والحروف

قبل تسليم النص، تحقّق من نوع الحد المطلوب: كلمات أم حروف، وهل تدخل المسافات وعلامات الترقيم في الحساب.

حول عداد الكلمات والحروف

يعرض عداد الكلمات والحروف مؤشرات سريعة للنص العربي أو الإنجليزي أو المختلط أثناء الكتابة واللصق. تظهر أعداد الكلمات والحروف والأسطر والحروف بعد حذف المسافات البيضاء، لتساعدك على مراجعة مقال أو واجب أو منشور قبل إرساله.

تذكّر أن كلمة «حرف» لا تعني الشيء نفسه في كل خدمة: قد تُحسب المسافات أو تُستثنى، وقد تقيس البرامج وحدات برمجية أو رموزًا مرئية أو حروفًا لغوية. هذه الأداة تتبع قواعد JavaScript محددة، ولا تحلل بنية العربية أو تفصل الكلمات صرفيًا. لذلك عند وجود حد رسمي للطول، اعتمد تعريف الجهة المستقبلة وقارن المؤشر المطابق له.

كيف نحسب؟

تتعامل الأداة مع قيمة النص كما هي. لحساب الكلمات تزيل الفراغات البيضاء من البداية والنهاية، ثم تقسّم السلسلة عند محرف مسافة بيضاء واحد أو أكثر؛ علامات الترقيم لا تُفصل عن الكلمات الملاصقة لها. عدد الحروف الكلي هو text.length، وهو طول سلسلة JavaScript بوحدات UTF-16، لا عدًّا للحروف بحسب قواعد العربية ولا بالضرورة عدد الرموز التي تراها العين. للمؤشر دون مسافات، تحذف الأداة المحارف المطابقة لنمط المسافات البيضاء قبل قياس الطول؛ وهذا يشمل فواصل الأسطر والتبويب. ويُحسب عدد الأسطر بتقسيم النص عند نهاية السطر LF أو CRLF. النص الفارغ يعرض صفرًا للأسطر، أما أي نص غير فارغ بلا فاصل سطر فيعطي سطرًا واحدًا. قد تستخدم خدمة أخرى تعريفًا مختلفًا للكلمة أو الحرف، لذا لا تقارن النتائج إلا بعد معرفة قواعد العد.

المعادلة أو طريقة المعالجة:

الكلمات = عدد الأجزاء بعد trim والتقسيم على whitespace؛ الحروف = text.length في JavaScript؛ دون مسافات = طول النص بعد حذف whitespace؛ الأسطر = عدد أجزاء التقسيم عند LF أو CRLF للنص غير الفارغ، وصفر للنص الفارغ.

طريقة الاستخدام

  1. اكتب النص أو ألصقه في مربع النص.
  2. راجع مؤشرات الكلمات والحروف والأسطر والحروف دون مسافات؛ تتحدث الأعداد مع تعديل النص.
  3. انسخ النص عند الحاجة، ثم قارِن المؤشر المناسب بحد الطول الذي تحدده الجهة المستقبلة.

أمثلة عملية

عبارة عربية قصيرة

«مرحبا يا عالم» تتكون من 3 كلمات، و13 وحدة JavaScript مع المسافتين، و11 دون المسافات، وسطر واحد.

الترقيم جزء من الكلمة

«Hello, world!» كلمتان و13 وحدة JavaScript مع المسافة، و12 دونها؛ الفاصلة وعلامة التعجب متصلتان بالكلمتين فلا تنشئان كلمتين إضافيتين.

فاصل سطر واحد

في النص «أ ب» كلمتان و3 وحدات JavaScript، منها فاصل السطر، ووحدتان دون المسافات البيضاء؛ ويظهر عدد الأسطر 2.

ملاحظات مهمة

  • تكرار الفراغات أو استخدام تبويب لا يضيف كلمات، لكنه يدخل في عدد الحروف الكلي. النص المكوّن من مسافات فقط يعطي صفر كلمات، لا نصًا فارغًا.
  • علامة الترقيم الملاصقة للكلمة تبقى ضمن الجزء نفسه؛ أما العلامة المفصولة بفراغ فتُعد جزءًا مستقلًا وفق قاعدة التقسيم، لا وفق تحليل لغوي.
  • قد تختلف نتائج عدادات الخدمات بسبب اختلاف تعريف الكلمة والحرف والرمز والمسافة. لا تفترض تطابقها؛ تحقّق من طريقة الحساب التي تعتمدها الجهة المطلوبة.

أسئلة شائعة

كيف تُحسب الكلمات؟

تُزال المسافات البيضاء الطرفية ثم يُقسّم النص عند المسافات؛ كل جزء كلمة.

هل تُفصل علامات الترقيم؟

لا؛ تبقى مع الكلمة الملاصقة، وتُعد مستقلة فقط إذا فصلها فراغ.

هل يحلل العداد صرف العربية؟

لا؛ يعتمد تقسيمًا برمجيًا بسيطًا على المسافات البيضاء.

ماذا يعني عدد الحروف؟

هو طول سلسلة JavaScript بوحدات UTF-16، لا عدد الحروف اللغوية.

كيف يحسب النص دون مسافات؟

يحذف الفراغات والتبويبات وفواصل الأسطر ثم يقيس طول الباقي.

كيف تُحسب الأسطر؟

النص الفارغ صفر؛ النص بلا فواصل سطرية سطر واحد، وتُحسب LF وCRLF.
