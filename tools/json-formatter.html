منسق JSON

JSON حساس لعلامات الاقتباس والأقواس والفواصل؛ المنسق يساعدك على قراءة البنية لكنه لا يصلح المعنى أو أسماء الحقول تلقائيًا.

استخدم منسق JSON

ألصق JSON صالحًا، ثم اختر التنسيق للقراءة أو التصغير للاستخدام داخل طلب أو ملف.

حول منسق JSON

ألصق بيانات JSON، ثم اختر التنسيق أو التصغير لمعرفة النتيجة ورسائل الخطأ.

طريقة الاستخدام

ألصق JSON صالحًا، ثم اختر التنسيق للقراءة أو التصغير للاستخدام داخل طلب أو ملف.

  1. ألصق البيانات كما وصلت من API أو الملف.
  2. استخدم التنسيق لرؤية الكائنات والمصفوفات المتداخلة.
  3. إذا ظهر خطأ، ابدأ من الموضع المذكور وراجع الفواصل والاقتباسات.

أمثلة عملية

كائن صالح

{"name":"test","n":1} صالح لأن أسماء المفاتيح والقيم النصية بين علامات اقتباس مزدوجة.

خطأ شائع

كتابة {name: test} ليست JSON قياسيًا؛ يجب أن تصبح {"name":"test"}.

ملاحظات مهمة

  • المعالجة محلية داخل المتصفح ولا ينبغي لصق مفاتيح سرية أو رموز وصول في أي أداة عامة.
  • JSON ليس JavaScript كاملًا؛ التعليقات والفواصل الأخيرة غير مسموحة في الصياغة القياسية.

أسئلة شائعة

هل يتم إرسال JSON إلى الخادم؟

لا، تتم معالجة البيانات داخل المتصفح.

ماذا أفعل عند ظهور خطأ؟

راجع رسالة الخطأ ومكان الخطأ، ثم تحقق من الفواصل وعلامات الاقتباس والأقواس.

لماذا محتوى أدوات؟

  • شرح وأمثلة عربية بدل نتيجة رقمية فقط.
  • أمثلة مالية بالريال السعودي عند ملاءمة الأداة.
  • معالجة محلية عندما تدعمها الأداة.
  • واجهة خفيفة ومناسبة للجوال.
