الرئيسية/الأدوات/منسق JSON

كيف أنسق JSON أو أتحقق من صحة صياغته وأعرضه مضغوطًا؟

أدخل JSON صالحًا لعرضه بمسافات بادئة أو كسطر مضغوط؛ وعند تعذّر تحليله تظهر رسالة خطأ في حقل النتيجة.

منسق JSON

احتفظ بنسخة من النص الأصلي قبل التصغير لتسهيل مراجعته أو تعديله.

حول منسق JSON

يساعدك منسق JSON على قراءة بيانات منسوخة من واجهة برمجية أو ملف إعدادات، بعرضها مرتبة أو مضغوطة. الصق المحتوى في حقل JSON الأصلي واختر الإجراء المناسب.

تعيد الأداة إخراج البيانات بعد تحليل الصياغة؛ لا تصلح الأخطاء تلقائيًا ولا تتحقق من معنى الحقول أو توافقها مع تطبيقك.

كيف تعمل الأداة؟

تحلل الأداة النص باستخدام JSON.parse. إذا نجح التحليل، تعيد كتابته عبر JSON.stringify بمسافتين بادئتين عند التنسيق، أو دون مسافات بادئة عند التصغير. إذا فشل، تعرض رسالة الاستثناء في حقل النتيجة.

المعادلة أو طريقة المعالجة:

تحليل JSON ثم إعادة إخراجه بتنسيق مقروء أو مضغوط.

طريقة الاستخدام

  1. الصق النص في حقل JSON الأصلي.
  2. اختر «تنسيق JSON» للعرض المرتب أو «تصغير» لإزالة الفراغات التنسيقية.
  3. راجع النتيجة؛ عند ظهور خطأ، صحح النص ثم أعد المحاولة.

أمثلة عملية

كائن بيانات

إدخال {"name":"ليلى","age":30} يظهر منسقًا على أسطر مع مسافتين بادئتين.

قائمة قصيرة

الإدخال [1, 2, 3] يصبح عند التصغير [1,2,3].

صياغة غير صالحة

الإدخال {name: "ليلى"} يفشل لأن اسم المفتاح غير محاط باقتباس مزدوج؛ تظهر رسالة خطأ بدل التصحيح.

ملاحظات مهمة

  • JSON القياسي لا يقبل التعليقات أو الفاصلة الزائدة قبل إغلاق كائن أو قائمة.
  • يجب إحاطة أسماء المفاتيح والقيم النصية بعلامات اقتباس مزدوجة.
  • التنسيق لا يتحقق من معنى البيانات أو أسماء الحقول، ولا يصلح النص تلقائيًا.

أسئلة شائعة

ما الفرق بين التنسيق والتصغير؟

التنسيق يضيف مسافات بادئة وأسطرًا للقراءة؛ التصغير يزيل الفراغات التنسيقية.

هل تصلح الأداة أخطاء JSON؟

لا؛ تعرض رسالة الخطأ، وعليك تعديل الصياغة بنفسك.

هل تقبل المصفوفات؟

نعم، يقبل محلل JSON المصفوفات وسائر قيم JSON الصحيحة.

هل تقبل التعليقات؟

لا، التعليقات ليست جزءًا من صياغة JSON القياسية.

لماذا يظهر خطأ عند وجود فاصلة أخيرة؟

الفاصلة قبل قوس الإغلاق غير صالحة في JSON القياسي؛ احذفها ثم أعد المحاولة.

هل يؤكد التنسيق أن البيانات مناسبة لبرنامجي؟

لا؛ نجاح التحليل يؤكد الصياغة فقط، وليس توافقها مع متطلبات برنامجك.
